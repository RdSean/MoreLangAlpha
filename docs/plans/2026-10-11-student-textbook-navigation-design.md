# 学生教材入口与阅读目录设计

用户已确认独立教材入口和目录收起方案，补充要求移除学生作业页「我的作业」标题区，并让日历底部略超出首屏。

- 学生导航增加「我的教材」，路由 `/education/learn`；列表复用学生学习分配 API，展示名称、知识点进度、继续学习及加载/空/错误状态。家长教材管理入口不变。
- 作业页不再承载完整教材列表，只保留跳转链接；教材详情返回独立教材列表，教材详情和总结页高亮教材导航，避免同时高亮作业。
- 阅读页复用 BookNavigator 的收起按钮。宽屏收起后正文扩宽，工具栏保留展开按钮；窄屏保留目录弹层。切换目录不卸载讲义或问答。
- 仅学生作业页移除标题区并允许纵向滚动。日历按视口和实际周数确定高度，不随日程/作业量无限升高；右侧作业在桌面独立滚动，手机上下排列。
- 复用 Quiet / NASA 主题、Lucide 图标及学生权限，不增加后端接口、不调整 Docker。
- 验证学生手机/平板/桌面导航、教材状态、目录收放后的正文与问答保留、日历高度和手势；覆盖实际 Chromium 90，更新中文变更日志并原子提交。
