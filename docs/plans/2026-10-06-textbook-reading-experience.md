# 教材阅读与提问体验优化

**目标**：依据用户的九条浏览器批注，统一家长工作台和学生学习页的紧凑目录、讲义排版与逐页追问。

**架构**：复用 BookNavigator、BookReader、EducationMarkdown 和既有 Flash/SSE 请求。教材学习状态与家长讲义会话保存在 education 独立模块，通过当前教材权限检查读取；学生继续使用原有授权学习会话。不另建分支，保留当前未提交文档和教材 PDF。

**技术**：React、React Query、现有语音输入 hook、FastAPI、async psycopg、Alembic。

## 实施顺序

1. 为目录单章/全局展开收起及阅读区移除重复 tab 加入回归测试；复用目录树，单行溢出标题按实际宽度平滑位移，底部固定导航 tab。
2. 修复教材根容器的高度约束；书名、返回和管理动作置于 aside 顶部，学生分配移到教材列表更多菜单；测量并局部复刻 Mentrix 的 Markdown 字体、字号、标题、引用、列表、表格及 code 样式。
3. 为逐页讲义追问加入测试；复用 Flash 请求与语音 hook，提供分页历史、讲义返回、待答/失败/重试状态，保持会话上下文绑定当前讲义。
4. 保存每位用户各知识点的阅读/提问状态，在目录中分别显示黄色、浅绿、绿色状态条及讲义完成勾号。
5. 执行 Education 相关测试、类型检查、后端相关测试和构建；浏览器验证桌面/移动高度与交互、局域网访问。每项实质变更验证后更新中文 CHANGELOG 并原子提交。

## 验收

- 页面不随目录或正文增长；目录与正文分别滚动，底部 tab/提问栏始终可见。
- 章节与全部章节可收起/展开，搜索期间仍显示匹配项。
- 新提问使用完整阅读区域回答，不追加狭小聊天卡片；历史可回看。
- 阅读与提问状态在刷新后保留且不同用户隔离；无讲义不显示已完成。
- 既有加工、原文件定位、授权、Flash/SSE/checkpoint 机制继续可用。

## 执行结果

- 实施顺序 1–5 已完成，迁移 088 已应用到本地开发数据库。
- 前端相关 195 项、后端相关 157 项通过，类型/构建、生产文件 ESLint、Ruff 和 diff 检查通过。
- 浏览器验证桌面/手机目录与正文内部滚动、底部固定控件、全部收起展开；家长两次真实 Flash/SSE 问答及刷新历史恢复通过，LAN 前端和后端健康检查均 200。
- 实际麦克风采集、学生真实账号问答、网络断流中恢复未实测；已有原文件/加工/学生路由回归通过，不作为上述真实全流程的替代。
