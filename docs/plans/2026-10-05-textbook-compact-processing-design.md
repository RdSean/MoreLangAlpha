# 教材加工紧凑时间线设计

用户已确认实施需求 1–9；需求 10（原 PDF 物理页码跳转）跳过，需求 11（讲义正文排版）另行讨论。

## 展示契约

- 工作台处理页以当前书名及真实原文类型、页数为标题；缺失页数不以 Markdown 行数替代。
- 结构与讲义使用各自当前任务的时间线，不叠加历史任务；批量仅展示当前项及完成数量。
- 服务阶段节点纵向连线，紧凑排列。当前动作使用 Shimmer；每个当前节点只刷新最后一条业务活动或诊断，业务活动仅展示上报时间。
- 不展示尝试历史、批量统计面板及增长的活动列表。真实准备进度、断线、失败、取消、部分提交与重试状态保留。
- 随机诗词沿用真实活动触发和五秒冷却；时间线下方居中两行显示诗句及作者，淡入淡出并尊重减少动态效果设置。
- 完成后下方显示可靠总耗时及 token 用量；缺失用量显示“未记录”。展示学习入口，保持手动跳转及首份成功讲义可读。
- 阅读状态隐藏“活动”入口；加工中可以切换加工页与阅读，并保留阅读位置及共享单一 SSE。
- 侧栏使用紧凑动画 tab，章节显示“章节名（知识点数量）”；原书目录仍打开既有 Markdown。
- 正常桌面与移动端竖屏一屏内展示；极短窗口或放大文字允许安全滚动，不遮挡状态和按钮。

## 边界

沿用 Quiet Workspace 设计系统、可靠计时及 PG 工作队列；不调整 Skill、模型推理、切分策略或 LangSmith。无需再次调用付费模型或删除教材。旧数据缺失字段显示未知，不做旧格式转换。仅隔离 langalpha_test 可运行重建测试。
