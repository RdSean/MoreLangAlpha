# 家长教材删除设计

用户确认不可恢复删除，保留图书馆原文件和解析产物。

教材列表提供家长专属删除图标、具名提示和确认对话框。对话框明确删除结构、讲义、活动、学生授权和学习记录，不影响图书馆来源。进行中任务禁止删除；请求时后端再次检查，不能仅依赖 UI 状态。

DELETE /api/v1/education/textbooks/{id} 返回204。家长身份和家庭归属在后端检查，跨家庭返回404，学生返回403。数据库事务锁教材与任务，检查任务及对应运行尚未结束的情况，按外键顺序清除学习关联、讲义、任务、结构及教材。PTC工作区、运行账本和checkpoint不由教材删除接口清除；学习问答线程沿用线程删除语义，共享学生Flash工作区保留。

同一事务登记无教材外键的持久清理记录，只允许清理 education/{household_uuid}/textbooks/{textbook_uuid}/ 精确前缀。文件清理在事务外执行；失败保留记录，由教育任务扫描重试，避免断电或存储故障遗失待清理目标。不枚举或删除图书馆及其他教材目录，不清除共享Docker挂载。

验证覆盖权限、活跃任务阻止、数据库关联清理、来源保留、并发与失败重试。UI覆盖确认取消、成功刷新、失败可重试和学生不显示入口。真实浏览器只删除专门创建的验收教材，执行前按浏览器要求再次确认。
