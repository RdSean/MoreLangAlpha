# 知识点讲义 PDF 导出设计

2026-10-09：用户确认直接下载 PDF，统一浅色导出。作用于当前仓库中的家长工作台与学生学习页；不改教材加工流程。

## 已确认交互

- 仅在当前知识点已有可读讲义的讲义视图显示分体按钮。默认导出讲义；下拉另选讲义及我的问答。
- 两种账号均使用既有教材/分配权限。问答仅限当前账号、当前知识点，不扩展为家庭全部对话。
- A4 纵向、15mm 页边距、白底深色字，保留中文、公式、表格、图片，连续分页和页码。界面主题不影响 PDF。
- 生成中显示加载反馈，防止重复提交。问答回答中禁用含问答的导出；无讲义不显示导出入口。失败保留阅读页面并明确提示。

## 数据与渲染

浏览器通过既有 Markdown/KaTeX 渲染讲义及公开问答，生成独立正文，不抓取页面 DOM、活动面板或 SSE 原始事件。问答读取现有按知识点隔离的公开接口，仅映射 user/assistant 的文本字段。

教育专用 POST 接口再次检查访问权限，读取当前讲义及可选公开问答，逐段校对前端提交的角色及 Markdown；变化时返回冲突，不混合两份讲义。严格 DTO 拒绝工具/推理等额外字段和超限内容。前端渲染的 HTML 仍是不可信排版输入，后端使用结构化 HTML parser 白名单清理，只保留正文与 KaTeX 的 MathML/SVG，不提供任意 URL 转 PDF 接口。

图片只允许当前教材的资产路径，由后端经既有授权/摘要校验读取并嵌入。外部或其他教材图片明确失败，不静默遗漏。KaTeX 字体由前端按需读取本地打包资源并嵌入；不引入远端 CDN。

复用现有 Chromium 生命周期与并发限制，新增通用静态文档渲染入口：独立上下文、禁用脚本、service worker 和网络访问，不携带登录 cookie；固定浅色 A4，等待字体/图片完成，超时及资源故障明确失败。PDF 只作为响应返回，不写 MinIO/数据库，也不调用模型。服务器生成标题和问答分段标签。

## 验收

后端：权限、当前账号/知识点、讲义变化、问答历史故障、工具字段拒绝、HTML 清理、资产归属、离线渲染、并发/超时和私有下载响应。

前端：分体按钮、默认模式、问答模式、空讲义/原文隐藏、回答中禁用、错误恢复及下载 URL 释放。真实 Chromium 检查 A4 尺寸、中文/数学/图片/跨页表格、PDF 文本与页面截图；375px/桌面、亮暗界面均可使用。
