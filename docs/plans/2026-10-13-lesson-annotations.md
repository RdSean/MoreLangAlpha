# 学生讲义标记与批注 Implementation Plan

**Goal:** 按参考截图在学生讲义正文选段后标记或批注，刷新恢复，支持颜色、编辑、删除与素材积累。

**Architecture:** 复用学生学习素材 CRUD 和 source_anchor JSON，无数据库迁移。Markdown 的 rehype 插件在已清洗 AST 上为可标注文本生成稳定偏移，并按原文引用和前后文恢复标记；讲义级 Context 隔离 assignment / 知识点，选区动作仍等待 pointerup。保持现有 Chat 和对照树稳定。

**交互:** 原有上下文操作旁加入标记与批注，四色使用主题身份色 tokens。宽屏批注显示在正文旁，窄屏或对照时点标记打开批注。保存、编辑、删除失败保留内容并可重试；素材读取失败展示错误而非空笔记。仅学生生成讲义，不扩展 PDF、答案、朗读或总结。

## 执行顺序

1. 先写定位和渲染回归：跨加粗/链接选段、重复句定位、讲义变化、安全排除公式/代码、重叠标记。运行确认缺失行为失败，再实现 AST 标记与 Range 定位。
2. 编写学生保存/恢复/改色/编辑/删除与错误保留的组件回归，再接 Context、选段工具栏、响应式旁注及笔记本素材入口。
3. 用隔离 Playwright API 验证 Quiet / NASA、手机/平板/桌面实际选段、刷新、修改/删除、Chat 草稿及无溢出；运行相关单元、lint、类型检查、构建和 LAN 检查。
4. 更新中文 CHANGELOG 与验收记录，在 feature/more-to-skills-textbook-refactor 创建本次功能的原子提交，保留无关工作区文件。
