# 家庭账户管理设计

**状态：已批准，2026-08-18。**

## 目标

在 `/settings` 下增加家长专用的家庭账户管理页，让家长创建和查看同一家庭内的学生账号，并查看每个学生专属 Flash 空间的状态和只读对话记录。

## 边界与非目标

- 学生账号继续只拥有自己的确定性 Flash 空间；不支持把家长普通工作空间分配给学生。
- 家长不维护空间名称、不删除空间、不替换空间、不发送消息、不编辑或删除学生线程。
- 不增加答题、二次密码、前端口令或其它基于界面的额外验证。浏览器只携带现有本地登录会话；是否同家庭由每个后端请求的授权逻辑决定。
- 本阶段提供创建学生账号、查看学生账号、查看 Flash 空间状态、浏览线程列表和只读回放；不提供学生账号删除、改密或改名。
- 复用现有 `users`、`education_memberships`、`workspaces`、`conversation_threads` 及回放投影，不新增账户或工作空间表。

## 授权模型

所有家庭管理接口在服务端执行以下检查：

1. 当前会话对应用户必须是 `education_memberships.role = 'parent'`。
2. 目标学生必须是同一 `household_id` 下 `role = 'student'` 的成员。
3. 读取空间或线程时，服务端根据目标学生的用户 ID 解析确定性 Flash workspace，并再次确认 workspace 所属用户就是该学生。
4. 任一检查失败都返回 `403`（不存在的目标成员可按现有约定返回 `404`），不依赖前端隐藏按钮。

学生不能调用家长成员/空间/对话接口；现有学生自己的 Flash 与教育 API 行为不变。

## API 设计

保留现有 `POST /api/v1/auth/children` 创建合同，并增加家长只读查询：

- `GET /api/v1/auth/members`：在现有成员结果基础上提供可选的学生 Flash 空间安全摘要（空间 ID、名称、状态、更新时间），不返回消息正文、对象路径或凭据。
- `GET /api/v1/auth/children/{student_user_id}/workspace`：幂等确保目标学生 Flash workspace 存在并返回安全摘要。
- `GET /api/v1/auth/children/{student_user_id}/threads`：分页返回该 Flash workspace 的线程元数据，支持现有排序/分页；仅同家庭家长可用。
- `GET /api/v1/auth/children/{student_user_id}/threads/{thread_id}/replay`：复用现有回放投影，改由家庭授权服务验证目标线程确属该学生的 Flash workspace 后以 SSE 返回只读事件。

这些接口不改变通用 `/api/v1/workspaces` 和 `/api/v1/threads` 的“拥有者才能访问”契约，也不向家长授予通用线程写接口。

## 前端体验

- `Settings` 新增 `tab=family` 二级标签“家庭账户”；仅家长显示，学生访问时显示无权限状态。
- 家庭账户页展示学生列表：姓名、登录标识、Flash 状态和“查看对话”入口。
- “添加子女账户”使用现有 Dialog/Form 组件，字段为用户名、姓名、初始密码；显示服务端约束提示（用户名格式、密码至少 12 位），提交按钮提供加载、成功和错误反馈。
- 学生详情保持在设置上下文中（`tab=family&student=<id>`），提供返回列表、空间状态和线程列表；选择线程后进入只读对话查看器，不渲染输入框、发送按钮、编辑、删除或分享动作。
- 对话列表和回放均有加载、空状态、失败重试和无权限状态；移动端保持纵向滚动，不引入新的一级导航。

## 数据流

1. 家长打开家庭账户标签，React Query 获取成员摘要。
2. 点击添加后调用现有创建接口；成功后失效成员查询并显示新学生。
3. 点击学生详情时调用 workspace 摘要和线程列表接口；后端按需创建确定性 Flash workspace。
4. 选择线程后使用回放 SSE 客户端读取已有事件，前端只做展示，不复用可发送消息的 `ChatAgent`。

## 错误处理

- `401`：现有登录失效处理，回到登录流程。
- `403`：显示“没有权限查看该家庭账户”，不暴露目标是否存在。
- `404`：学生或线程不存在，返回列表并给出可恢复提示。
- `409`：用户名已占用，保留表单输入并提示更换用户名。
- `422`：显示服务端字段校验错误；不在前端复制一套会漂移的授权规则。
- 网络或回放失败：显示重试动作，不改变已加载的列表状态。
