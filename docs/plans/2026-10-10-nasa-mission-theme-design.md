# LangAlpha NASA Mission 主题设计

**日期：** 2026-10-10  
**分支：** feature/more-to-skills-textbook-refactor  
**范围：** Web 前端全局浅色主题系统与教材学习会话视觉升级

## 目标

在不修改 Docker 中间层、后端 API、SSE、React Query、工作区、沙箱或教材学习数据流的前提下，为 LangAlpha 增加一套可切换的浅色 NASA Mission 主题。保留现有 Quiet Workspace 浅色主题，移除深色和系统自动跟随选项。

NASA Mission 覆盖 App shell、侧栏、移动底部导航、共享 UI primitives、聊天/文档/自动化/设置/仪表盘页面，以及学生教材学习会话。主题选择集中在语义 token 层，页面组件不根据主题名称分叉业务逻辑。

## 已确认的产品决策

- 主题选项为 Quiet Workspace 与 NASA Mission。
- 旧的 `light`、`dark`、`auto` 本地偏好在读取时迁移到 `quiet`，避免旧用户进入无效主题。
- 主题根属性使用 `data-theme="quiet"` 与 `data-theme="nasa"`。
- 只维护浅色视觉；深色 favicon、深色 canvas 与暗色设置选项从用户路径移除。
- NASA Mission 作为全局主题可用，不仅限于教育页面。
- 教材学习会话是第一优先级视觉示范面，功能和请求路径保持不变。
- 现有工作区中已修改的业务计划文件与未跟踪教材 PDF 不属于本次主题提交。

## 视觉语言

### 基础表面

- 页面底色：暖白纸张 `#ECE5D6`。
- 内容面板：`#FFFFFF`。
- 主文字：`#171717`。
- 次要文字：`#5F5B53`，辅助文字至少满足 3:1 对比度。
- 面板和接缝：1px 深灰细线，主要区域使用 16–24px 内边距。
- 圆角：默认 2–4px，避免大圆角卡片和悬浮胶囊。
- 阴影：仅保留低强度纸张层次，不使用发光、玻璃效果或大面积渐变。

### 颜色层级

身份色只承载分类和识别：

- 深蓝灰：`#4C5A68`
- 橄榄绿：`#7A7F4E`
- 纸张金：`#D2A85E`
- 砖红棕：`#A8432F`

唯一鲜艳强调色：

- 行动红：`#D63A2C`

行动红只用于主行动按钮、关键当前状态、阻断/错误标记和少量进度强调。身份四色不可替代行动红，也不作为大面积按钮背景。

### 排版

- 中文正文沿用项目当前中文字体链，保证教材长文阅读稳定。
- 英文标题和界面文字使用 Helvetica/Arial/系统无衬线，标题使用较高字重和适度字距。
- 编号、状态码、时间、方向标签使用现有等宽字体 token。
- 标签采用小号全大写和字距，例如 `MISSION 04`、`STOW 84S`、`THIS SIDE UP`。
- 正文最小移动端字号保持 16px；标题、正文、标签有明确层级。

### 图案与材质

- 黑白警示斜纹只出现在危险操作、处理态、抽屉边缘或空状态的非正文区域。
- 低透明度划痕、胶带和手写提醒只作为大块面板背景伪元素，禁止覆盖正文、控件和可读信息。
- 身份元素使用四色复古彩条与圆形任务徽章。
- 不使用霓虹、全息、扫描线、强渐变、强噪点或装饰性动效。

## 主题架构

### ThemeContext

`ThemeContext` 的公开类型改为：

- `ThemePreference = 'quiet' | 'nasa'`
- `ResolvedTheme = 'quiet' | 'nasa'`

`getInitialPreference` 读取 `localStorage.theme`：

- `quiet`、`nasa`：直接使用。
- `light`、`dark`、`auto` 或未知值：迁移为 `quiet`。
- 没有值：使用 `quiet`。

系统媒体查询监听、深色 favicon 选择和三态 `toggleTheme` 逻辑删除。根节点在 layout effect 中设置 `data-theme`，favicon 固定为浅色资源。

### CSS token 层

`tokens.css` 分为：

1. 共享 token：字体、间距、触控尺寸、动画、语义状态和组件尺寸。
2. `[data-theme="quiet"]`：保留现有浅色 Quiet Workspace 值。
3. `[data-theme="nasa"]`：NASA Mission 值。

页面和组件继续只引用 `var(--color-*)`、`var(--font-*)`、`var(--radius-*)` 等语义变量。NASA 专属变量包括纸张底色、身份四色、行动红、警示斜纹、彩条和划痕透明度。所有新 token 必须通过 token 引用测试。

### 设置入口

现有设置页主题区改为两个主题选项：

- Quiet Workspace
- NASA Mission

控件显示主题名、简短描述和可识别的配色预览。删除 dark/auto 选项，保留键盘焦点、语义按钮和当前选中状态。主题切换后不刷新页面，不影响业务状态。

## 组件与页面改造

### App shell

- 侧栏采用任务控制台分区：细线、任务编号、圆形用户任务徽章、四色身份条。
- 当前导航使用行动红的小型边缘标记；其他导航只用中性颜色。
- 移动底部导航取消大圆角悬浮胶囊，改为带顶部分隔线的任务栏。
- 共享按钮、输入框、菜单、弹窗、卡片、分页和加载态统一边框、圆角和触控尺寸。
- 保留现有折叠、拖拽宽度、路由高亮和移动安全区逻辑。

### 教材学习会话

涉及 `StudentTextbookLearningPage`、`BookNavigator`、`BookReader`、`LessonConversation`、`PersonalNotebook` 及其样式。

桌面布局：

- 左侧教材目录。
- 中央可读宽度的正文/讲义。
- 右侧或会话内的问答与工具区。
- 面板之间有细线和接缝，不使用大面积卡片阴影。

移动布局：

- 顶部任务栏展示返回、教材编号、当前知识点标签。
- 正文单列滚动。
- 目录、笔记和辅助操作使用现有 Dialog/Sheet 机制。
- 底部输入/操作栏遵守安全区，滚动内容预留底部空间。
- 所有可点击区域至少 44px。

状态表达：

- 未读、已看、已提问等学习状态使用中性标记与身份色。
- 处理中、错误、阻断等状态使用黑白斜纹和行动红文字/标记。
- 任务徽章和章节编号承担识别功能，颜色不作为唯一状态提示。

### 其他页面

ChatAgent、Documents、Automations、Settings、Dashboard、Plugins 和登录页统一迁移到语义 token。优先清理：

- 深色默认背景和 hard-coded 深色文字。
- 大圆角悬浮胶囊。
- 强渐变、发光和非语义颜色。
- 直接写死且与主题 token 重复的颜色。

不改变页面业务布局、API 调用、数据查询、SSE 或权限行为。

## 可访问性与响应式要求

- 正文对比度至少 4.5:1，辅助文字至少 3:1。
- 所有图标按钮保留 aria-label、title 或可见标签。
- 触控区域至少 44×44px。
- 键盘焦点使用清晰中性 focus ring，不依赖行动红单独表达焦点。
- 颜色不作为唯一状态标识，状态同时有文字、图标或纹理。
- 支持 `prefers-reduced-motion`，动效控制在 150–250ms。
- 检查 375px、768px、1024px、1440px，并验证横向滚动、输入法和安全区。

- 设置页主题选择与可访问状态。
- token 引用测试不出现未声明变量。
- 教材学习页、目录、阅读器、会话和笔记现有行为回归。

构建检查：

- `pnpm typecheck`
- `pnpm test`
- `pnpm build`
- 必要的 ESLint 与关键路径预算检查。

浏览器验收：

- `pnpm dev --host 0.0.0.0 --port 5177`
- Quiet Workspace 与 NASA Mission 主题切换。
- 教材桌面、平板、手机布局。
- 教材目录抽屉、笔记、问答输入、导出、处理/错误状态。
- 访问 LAN 地址返回 200。
- 关键页面截图回归不出现正文遮挡或横向溢出。

## 风险与回滚

- 全局 token 改动可能影响大量旧页面：先保留 Quiet token，NASA 只通过根主题覆盖；每阶段运行类型、单元和构建检查。
- 移除 dark/auto 可能影响旧测试和外部脚本：提供旧值迁移，并更新测试 fixture。
- 页面中仍可能存在直接颜色字面量：通过 `rg` 扫描、token 引用测试和截图回归逐步收敛。
- NASA 纹理若过强会影响阅读：纹理限制在伪元素、低透明度和大块空白区域，必要时用 CSS 开关快速禁用。
