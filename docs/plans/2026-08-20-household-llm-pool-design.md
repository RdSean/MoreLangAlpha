# 家庭模型池设计

**状态：已批准（2026-08-20）。**

## 目标

将家庭中的 LLM Endpoint 统一归属于家庭模型池，由家长维护，学生账户只负责使用和选择模型。
学生不再维护自己的 Endpoint、API Key 或供应商配置。家长后续新增、修改、禁用模型时，学生下一次请求立即使用最新的家庭模型池。

本设计适用于当前测试数据库。实施前允许清理现有用户级 LLM 配置、模型偏好、相关测试记录和旧对话数据，不设计兼容迁移链路。

## 方案决策

### 采用家庭级模型池

模型配置不在创建学生账户时复制，也不通过复制用户级 API Key 实现同步。每个家庭拥有一组 Endpoint，Endpoint 的加密凭证只保存一份。

家长是模型池管理员；学生是模型池使用者。家长自己的聊天也可以使用家庭模型池。

### 方案比较

1. **创建时复制家长配置**：初期实现简单，但会产生配置漂移、密钥重复、删除同步失败和账单归属不清等问题，不采用。
2. **运行时回退到家长用户配置**：改动较小，但模型仍然归属于某个用户，家庭权限和生命周期不清晰，不作为最终结构。
3. **家庭级模型池（采用）**：配置、权限和账单归属天然以家庭为边界；家长修改一次即可影响所有学生，适合当前可重建测试数据库的条件。

## 数据模型

建议新增以下概念，字段名称可在实施计划中根据现有命名约定调整。

### `household_llm_endpoints`

- `endpoint_id`：稳定 UUID，历史记录引用该 ID，而不是只保存模型字符串。
- `household_id`：所属家庭。
- `display_name`：家长维护的显示名称。
- `provider`、`model`：供应商标识和模型标识。
- `base_url` 或其 Vault 引用：服务端使用，学生接口不返回完整凭证信息。
- `secret_ref`：加密凭证引用，密钥仍通过现有 Vault/加密访问层解析。
- `enabled`：是否对家庭成员可用。
- `sort_order`：模型池显示顺序。
- `created_by`、`created_at`、`updated_at`：审计字段。

### `household_llm_settings`

- `household_id`：唯一家庭标识。
- `default_endpoint_id`：可为空的家庭默认模型。

### `student_llm_preferences`

- `user_id`：学生账户。
- `endpoint_id`：学生当前偏好的家庭 Endpoint，可为空。
- `updated_at`：偏好更新时间。

偏好只表达“学生下次使用哪个家庭模型”，不授予 Endpoint 管理权限。Endpoint 被禁用或删除后，偏好自动失效。

## 模型解析规则

学生请求的有效模型按以下顺序解析：

```text
学生个人偏好（存在且仍启用）
    ↓
家庭默认模型（存在且仍启用）
    ↓
无模型
```

- 学生第一次使用且没有个人偏好时，使用家长设定的家庭默认模型。
- 学生手动选择模型后，保存为自己的偏好；家长修改默认值不覆盖该偏好。
- 学生偏好对应的 Endpoint 被禁用或删除时，清除失效偏好并回退到家庭默认模型。
- 家庭没有默认模型时，不自动选择模型、不报错；如果模型池中存在启用的 Endpoint，学生可以手动选择。
- 模型池为空时，学生显示“暂无可用模型”，发送请求前不进入 LLM 运行链路。
- 家长删除或禁用 Endpoint 后，新请求按上述规则重新解析；已经开始的运行不被中途切断。

父母和学生均不再从学生自己的 `user_api_keys` 或个人模型配置解析家庭模型。测试数据库清理后，不保留学生独立 Endpoint 的双轨行为。

## API 和界面

### 家长接口

```text
GET    /api/v1/family/llm-pool
POST   /api/v1/family/llm-pool
PATCH  /api/v1/family/llm-pool/{endpoint_id}
DELETE /api/v1/family/llm-pool/{endpoint_id}
PUT    /api/v1/family/llm-pool/default
```

所有写接口都要求当前账户是家庭家长，并在数据库层验证 Endpoint 属于当前家庭。

### 学生接口

```text
GET /api/v1/family/llm-availability
PUT /api/v1/family/llm-preference
```

学生只能读取启用的模型摘要和当前有效偏好，并更新自己的 `endpoint_id`。接口不返回 API Key、完整 Endpoint 地址、Vault 引用或其他家庭成员凭证信息。

### 家长页面

在 `/settings` 的账户/模型池区域提供：

- 模型列表和启用状态。
- 新增、编辑、删除 Endpoint。
- 设置或取消家庭默认模型。
- Endpoint 的显示名称、供应商和模型信息。

### 学生页面

学生聊天模型菜单只显示家庭模型池中的启用模型：

- 当前值优先显示学生偏好，其次家庭默认模型。
- 没有默认值时不自动选择，学生可手动选择。
- 选择后保存学生偏好。
- 模型池为空时显示无可用模型状态，不能发送没有模型的请求。
- 不显示 Endpoint 管理入口、凭证设置入口或个人 LLM 配置入口。

## 权限、安全和账单

- UI 隐藏只负责体验，所有 Endpoint CRUD、家庭归属、学生偏好写入都由后端强制校验。
- 解析器通过当前用户的家庭成员关系获得 `household_id`；不能接受前端传入的任意家庭或家长 ID 作为信任依据。
- 凭证只在服务端解析，学生永远不能读取家长 API Key、完整 Base URL 或 Vault 内容。
- 每次运行记录 `household_id`、发起用户、Endpoint ID、逻辑模型和最终解析模型。
- 账单归属为家庭/家长凭证，审计信息保留学生发起者，家长可以按学生查看使用情况。
- 历史记录保留模型名称快照，Endpoint 后续改名、禁用或删除不影响历史会话回放。

## 错误和边界行为

- 学生没有可用模型：返回明确的无模型状态，不创建 run、不写入空模型请求。
- 学生试图管理模型池：返回 `403`，前端不提供管理入口。
- Endpoint 不属于当前家庭：返回 `404` 或统一的禁止访问结果，不泄露其他家庭记录。
- 家庭成员关系被移除：后续模型池查询和 LLM 解析立即失效。
- 家长禁用学生当前偏好：下一次请求自动回退家庭默认模型；若默认模型也不可用，则回到无模型状态。

## 测试和验收标准

后端至少覆盖：

- 家长可以创建、修改、禁用、删除和设置默认 Endpoint。
- 学生不能执行 Endpoint 管理操作，只能更新自己的偏好。
- 学生模型解析优先级、失效偏好回退和无模型状态。
- 跨家庭 Endpoint、错误角色和失效成员关系均被拒绝。
- 凭证不出现在学生 API 响应、SSE、历史回放或日志中。
- 账单同时记录家庭/凭证归属和学生发起者。

前端至少覆盖：

- 家长模型池管理页面的增删改、启用状态和默认模型。
- 学生模型列表、首次默认、手动切换和偏好持久化。
- 无默认模型、空模型池和 Endpoint 被禁用后的状态。
- 学生不能进入家长模型管理页面。

验收重点是：家长新增或禁用 Endpoint 后，学生无需重新配置即可在下一次请求中看到最新模型池；学生切换模型后，后续会话继续使用自己的偏好，且不影响其他学生或家长默认值。
