# 家庭 ICS 日历设计

用户已确认：ICS 文件默认属于家庭，所有家庭成员共享查看；家长在设置的家庭账户中导入、更新和移除。教育日历显示每日共享日程，切换孩子不影响日程，日程不参与作业积分。

后端使用 icalendar 和 recurring-ical-events 处理 VEVENT、全天和跨天事件、时区、RRULE、EXDATE、RECURRENCE-ID。通过 Alembic 衔接现有迁移头新增家庭日历源表，保存经过校验的 ICS 内容、文件名、摘要和导入数量。重复导入同一文件更新源，相同内容不重复创建；按家庭限制所有读写操作。

按查询月份展开事件，限制文件大小、事件数量、来源数量、查询范围和处理时间。异常文件明确返回错误，失败导入不修改已有数据。不下载 ICS 引用的外部资源。本次不包含 URL 自动订阅。

前端沿用现有主题和 React Query：按家庭及日期范围缓存，写入后失效，焦点刷新，账户切换由现有认证缓存清理管理。界面覆盖移动和桌面。

验证：解析与例外规则测试，家庭共享/跨家庭拒绝及重复更新的真实 PostgreSQL 测试，迁移升级/回滚/再升级，前端交互和移动/桌面截图，构建与局域网访问。
