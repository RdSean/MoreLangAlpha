# 数学知识点的材料写法

当前 KP 的目标是数学概念、运算、证明、量或图形关系时读取本文件，包括英文数学教材。它只指导讲义组织，不改变主 Skill 的来源、引用、粒度、深度和宿主交付规则。

## 先抓住要学会的事

依据原文和用户目标，确定本条是在解释概念、学习计算方法、理解推导，还是读取图表/解决原有问题。`Task` 是题目形式，不是英语阅读技能标签。术语解释服务于数学理解，不自动生成英文词汇表、音标、词源、逐句语法或“批判性思维”段落。

| 内容 | 可用的组织方式 |
|---|---|
| 概念 | 要解决的问题 → 概念含义及条件 → 原有表示/图示/例子 → 简短要点 |
| 计算与操作 | 目标 → 必要概念 → 原例题逐步处理及每步理由 → 原有验算/相关易错处 |
| 推导或证明 | 已知与要说明的结论 → 依据明确的推导 → 条件与结论的边界 |
| 图表与应用 | 图中量、单位和关系 → 原问题的求解 → 结果及其实际含义 |

这些不是固定标题或必做步骤。合并小节、直接讲例题都可以；不要为填模板新增题目、故事、观点讨论或全单元复习。没有原有例题时，不把自动造例题当必需动作；辅助示例仅在用户范围允许且确有解释必要时使用，并与原书示例区分。

## 深度与受众

- 摘要：核心结论、关键条件、必要的表示，避免全套逐题展开。
- 讲义：解释“是什么、为什么这样做、怎样用”，讲清原有例子和题目的关键步骤。
- 精讲：深化同一个目标的依据、表示之间的关系和适用边界；不因精讲改为英语课或扩展到新知识点。

对低龄读者用他们能理解的语言解释原有表示，但不以口诀替代条件或制造错误类比。中文讲义需要英文术语时，核对标准名称并简短对照；术语小结只是可选，不必让孩子学习音标和词源。

## 写入前核对

核对实际出现的关键主张即可，不把下面变成讲义板块、额外交付物或反复规划清单：

1. **条件与对象。** 定义、运算、结论针对什么对象，有哪些前提或不能取的值？不要把“某个值无效”写成“所有零都无意义”，也不要把一个例题的操作限制推广到一般规则。
2. **等式、单位与实际量。** 数值关系、单位和实物所代表的量分别是什么？数值相等与图中实际量相等不是同一断言；简化的日常表述不能抹掉这一区别。
3. **推导与计算。** 每步与上一行一致，单位、符号和结果一致；需要时用现有执行工具核算确定的计算、代回原题或用来源提供的方法检查。举例成立不等于一般命题已证明，不发明原文不存在的标准答案。
4. **图示与文字。** 真正读取相关图再解释；分清分割的间隔、边界刻度和取到的部分，标明单位/整体。看不清图时说明缺口，不从文件名推断图中信息。
5. **来源与补充。** 原文的条件、脚注、图注和跨章依据继续保留；自己的解释不能冒充原书结论。原书明显错误或解析不清时，说明差异和限制，不默默复制或声称已纠正全部问题。

核对不能保证模型准确；同一模型再看一次不是独立校验。无法核实的关键推导/图义应标明限制或省略不必要断言。直接写最终 Markdown，不另写一份完整草稿或数学审核报告。
