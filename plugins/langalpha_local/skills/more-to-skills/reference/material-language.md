# 语言学习知识点的材料写法

当前 KP 的目标确为阅读、听说写、语法、词汇或语言表达时读取本文件。连续英文、课文形式或含 `Task` 不是充分理由：英文数学或科学概念应按其实际学科目标处理。本文件沿用原 Skill 的四族，但它们只在语言目标下适用，不改变主 Skill 的来源、引用与宿主职责。

## 先区分语言学习目标

中文语文阅读/写作围绕文章内容、语言感受、文本依据和表达方法展开：带学生读懂关键词句与人物/情绪/论证，再用原任务说明怎样从文本得到判断。写作任务解释原有表达方法及其作用；不套英语词缀、音标、逐句语法或视频板块，也不把每段都写成文学术语鉴赏表。

英语及其他外语学习同时处理需要理解的内容与本条语言目标，选择下文适用族。输入是中文翻译、双语注释或中文讲解时，原有外语学习目标仍可能成立；反之英文数学说明不因此成为英语课。其他外语只用对应语言的真实表达，不编造英语版板块或术语。

## 外语内容按本条目标选必要部分

| 族 | 可用骨架 | 来源信号（在语言目标确认之后） |
|---|---|---|
| 正文族 | 本条目标 → 分段内容与关键句解释 → 原有理解任务 → 与目标有关的结构/表达 → 小结 | 连续阅读正文 |
| 技能族 | 技能含义 → 原文操作方法 → 原有题组及依据 → 小结 | 阅读/听说写策略与对应 Task |
| 词汇族 | 语境与词义 → 原有任务 → 来源中的词缀/搭配/辨析 → 小结 | `VOCABULARY PRACTICE`、`WORD LINK`、词框等 |
| 视频族 | 观看目标 → 必要表达 → 原有主旨/细节任务 → 资料缺口或小结 | `BEFORE YOU WATCH`、`WHILE YOU WATCH` 等 |

同一 KP 有多种语言内容时按实际主目标组织，视频/词汇/技能/正文的旧判定顺序可作辅助，不应凌驾于学习目标。骨架不是固定清单；不为满足它而增练习、词汇或讨论。阅读文章若只有学科内容目标，不强制讲句法；混合目标只组合所需部分。

## 深度

- 摘要：核心内容、策略或表达及必要条件，不展开逐题讲解。
- 讲义：使目标读者理解原文并掌握本条语言技能；解释相关关键句/表达及原题依据。
- 精讲：按目标深化句法、指代、语用、搭配、辨析或原题意图；没有连续正文就不强制逐句讲，没有语言分析目标也不填音标/词源。

词源、同族词和音标只有在当前目标需要且可靠时出现；不要求每个词都有四项，不自动外扩一串词。遵守主 Skill 的关键句引用限额；逐句定位只引用不超过 10 词的原句片段，不复制整篇原文或虚构行号。需要的真实溯源集中在头部/必要注释，不在每段标题堆加工说明。

## 条件内容与资料缺口

- 热身、回扣练习只在当前 KP 的范围真有相应任务时解释，不重复邻条已经消费的题目。
- 批判性讨论只在原任务或用户目标需要时加入；没有这种目标时，不给普通概念检查冠以“批判性思维”标题。
- 脚注服务于理解当前内容；只有相关词义确需学习时才讲词汇，不把每个脚注变成词表。
- 单元首末位置不自动加路线导览或全单元词汇总复习；确需位置/回指时依据已读结构和原文，保持本条可独立阅读。
- 原有题目要说明依据；开放题的示范与标准答案区分。只有标题或任务但没有正文、音视频或答案时，讲清可确定的操作和缺口，不凭主题猜细节、编视频内容或假定答案。
- 用户限制只讲原题、不增例题或不扩展时优先服从。中文讲解中的生成表达示范标清性质，不冒充原书引用。

本条确有科学/数学等内容时，不能为了语言流畅改变事实。必要时结合对应学科 reference，但不拼接完整模板；直接写最终文件，完成、入库与指针仍由宿主确认。
