# PDF→Markdown 解析坑清单（跨书种通用）

> 来源：早期 `textbook-md-structure-extract` 技能（已废弃）中的实测经验，v2.0.0 起并入本流水线。
> 这一页讲**解析产物本身有什么毛病**，怎么在 Step 3-B（语义归一化）与 Step 3D-a（分块）时识别和绕过。与书种无关：任何 PDF→MD 的产物都会命中其中几条。
> P1–P7 是结构侧（影响节点与锚点），P8–P10 是分块侧（影响知识单元切分的输入）。

---

## 0. 动手前先探底：产物的覆盖范围

**不要假设解析产物是完整的。** 它经常只覆盖全书的一部分，而文件看不出残缺。三件事必须先回答，并写进 `coverage`：

```bash
wc -l -c "<file>"                                  # 规模
grep -n "^#\{1,4\} " "<file>" | head -200          # 全部标题
tail -20 "<file>"                                  # 是否停在正文中段
grep -c "^{[0-9]" "<file>"                         # 页标记数（Datalab 类产物）
grep -o "^{[0-9]*}" "<file>" | tr -d '{}' | sort -n | tail -3   # 最大页号
```

**最强的完整性判据是页码标记。** Datalab 类解析产物每页开头输出一行 `{n}----`。把页标记的**最大值**与目录表（CONTENTS）的末页对照，就能判断是否被截断。实测关系：

```
印刷页号 = 标记值 + 1
```

（用「单元起始页 / 样张页」交叉验证过。）当页脚的印刷页码整段丢失时（很常见），这是**唯一的页码来源**，可据此反推每个节点的 `page_range`。

> ⚠️ 教训案例：同一本教材的两个 md 版本，一个只有 1,531 行，看着像整本，实际只到第 3 单元正文中段；另一个 6,305 行是完整的。**不要凭"这本书以前是残卷"下结论，每次都要实测。**

**即使正文大面积缺失，也要从 CONTENTS / SCOPE AND SEQUENCE 表里把全册骨架捞回来**——那是全书唯一完好的元数据，价值最高。

## 1. 通病表（P1–P10）

| # | 症状 | 处理 |
|---|---|---|
| **P1** | **板块标题被降级为普通段落**。标题标记没生成，标签直接接在题目文本前（`CRITICAL THINKING` 最常见） | 段落级扫描补全：`^\s*\**<标签>\**\s`；标签取其后 1–3 个 Title-Case 词，**遇到 `The` / `This` / `What` / `In` / `Read` / `Look` 等句首词即停**。落在已有同名标题 ±3 行内的判为「正文重复标题」，跳过 |
| **P2** | **加粗标记破损**：`- COMPLETION** A. ...` 缺开头的 `**` | 清洗时正则修复：`^- ([A-Z ]+)\*\*` |
| **P3** | **长图注与正文粘连**：图片描述文字（"A woman with blonde hair…"）被拼到标题前 | 以「A/An/The + 描述」特征识别并切分；标题匹配统一用 `endswith` 而非全等 |
| **P4** | **正文截断** | 在 `coverage.gaps` 里写明截断行号与所在章节，`severity: high` |
| **P5** | **同级标题层级不稳定**：同一板块在不同章节分别是 `###` / `####`；个别大标题被降级 | **层级仅当线索**，语义与目录表清单为准。原始 md 层级另存一个自定义键（如 `md_level`）便于回溯 |
| **P6** | **页脚「章节号 + 页码」大量丢失**（往往全书只剩样张那两处） | 不要依赖页脚，改用 §0 的页标记反推印刷页 |
| **P7** | **章节范围末尾多算一页**：结束行恰好是下一页的 `{n}----` 分隔行 | 求末页时跳过纯分隔行与空行：取区间内最后一个「非空且不匹配 `^\{?\d+\}?-+$`」的行 |
| **P8** | **页码分隔行混在内容里**：`{8}--------` 这类行与正文之间可能没有空行，切块时会跟相邻内容粘成一块，被当成正文 | 切块时**先把纯页标记行单独成块**（`kind: page_marker`），交给下游忽略。**它是脚注归属的唯一锚**，不能丢——见 P9 |
| **P9** | **脚注定义有三种形态、且编号在书内重排**。形态：① `**1** **Term** is …`；② `<sup>2</sup> **Term** are …`；③ 裸编号 `1 Term **bold** is …`（Reading B 那种）。**每课从 1 重新编号** | 三种形态都要认；**绝不能用编号去重**（第 1 章的 `<sup>1</sup>` 与第 7 章的无关）。归属判据是**页标记**：定义行必须落在引用所在页或下一页（段落跨页时定义被推到下一页）。另需排除**填空题编号**——`<sup>1</sup>\_____` 后面跟着下划线，是题号不是脚注 |
| **P10** | **段落字母格式不齐**：同一篇课文里 A–D 带列表前缀（`- A Throughout …`）、E–G 不带（`E The story …`）。且**图注常以 A/An 开头**（`A visually impaired skier …`），会与「段落 A」撞车 | 归一化成 `para_label`：只认**大写**单字母 + 空白（小写 `- a.` 是选项、`- C.` 带点是小题编号，都要排除），并设长度阈值挡掉短句。图注抑制用「有没有 `- ` 前缀」判定——正文段落 A–D 带前缀、图注从不带 |

## 2. 作业纪律

- **不要 `Read` 一次性读超大 md**（>20k tokens / >256KB 会报错）。用 offset/limit 分段读，或 `grep` + `sed` 取片段——见 SKILL.md Step 2.6。
- **不要因为只看到 3 个单元就认为全书只有 3 个单元**：先查 CONTENTS 表。反之也不要因为 `tail` 看着像结尾就认定完整：先数 `{n}` 页标记。
- **不要把练习小题标签当独立节点**。`#### GIST`、`#### DETAIL` 这类属于「阅读理解」的题型，应归到其父节点下；只有出现在板块级的同名标签才是独立板块。
- **不要相信层级标记，要相信语义**。视觉层级（`##` / `###` / `####`）经常与真实结构错位，最终以「这段内容的性质」为准。
- **整本书（10+ 单元 / 数千行）写脚本处理，不要手工列表**。手工列表必然错行号，而锚点是本格式唯一的硬要求。
- **同一系列的教材版式一致**，脚本只需替换几张映射表（阅读 A/B、视频、目录表）即可跨册复用。

## 3. 与流水线的接口

| 坑 | 在流程里对应哪一步 |
|---|---|
| P1 / P3 / P5 / P7 | Step 3-B（语义归一化）时识别，影响节点是否成立与锚点边界 |
| P4 | 写进 `coverage.gaps`，`severity: high` |
| P2 | Step 2 抽取后的文本清洗 |
| P6 | `page_range.source: "derived"`，并在 `notes` 说明推导依据 |
| **P8 / P9 / P10** | **Step 3D-a（`tools/split_blocks.py`）**——这三条都由脚本确定性处理：页标记单独成块、脚注按页归属、段落字母归一化。它们的产物（`blocks.json` 的 `kind` / `footnotes[].referenced_by` / `para_label`）是 Step 3D-b 与 Step 7 的直接输入 |
| §0 覆盖范围 | 决定 `coverage.scope` 与 `coverage.excluded` 的边界 |
